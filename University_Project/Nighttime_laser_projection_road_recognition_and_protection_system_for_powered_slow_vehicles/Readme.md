# 專題簡介

光線不佳、騎行視角…等，都是會讓騎乘者無法及時發現路況變化的因素之一，因此本作品希望透過網狀雷射的投影對前方路況進行掃描的動作，當道路是平坦路況時，網狀雷射投影出的結果會呈現一個完整的網狀影像，若當道路有坑洞或是凹凸起伏不定時，網狀雷射投影出的結果會呈現一個不完整的網狀影像，有可能是缺一個邊、點與點的連線消失…影像狀況，並透過網狀雷射的影像是否完整以此達到警示騎乘者的功能，讓騎乘者能夠提早發覺路況有變化進而做出相應措施。同時利用攝影鏡頭將路況捕捉並記錄下來，藉由雷射變化為依據將路況進行影像辨識後的結果傳至 MCU (HT32F52352) 中，透過單晶片控制蜂鳴器提醒騎乘者前方路況發生異常。為了避免視線死角或是應注意而未注意而產生的交通意外，在車身兩側及後方安裝一字雷射模組對自身車身的行車範圍進行雷射投影用於警示其他用路人，實現防護功能的同時也結合了方向燈的功能用於警示其他用路人騎乘者的行車方向。

# 研究方法

本專案整合影像辨識、微控制器控制、UART 通訊及 LoRa 無線傳輸技術，建置一套可即時判斷道路距離狀態並提供聲光警示的智慧安全輔助系統。整體架構分為「影像辨識主系統」與「後方警示子系統」，透過有線及無線通訊協定完成辨識結果與控制指令的傳遞。

在影像辨識方面，首先使用 Teachable Machine 建立以 TensorFlow 為基礎的影像分類模型，完成訓練後再將模型轉換為 OpenVINO Intermediate Representation（IR）格式，以提升模型在邊緣運算平台上的推論效率。程式開發採用 Visual Studio Code 與 Python，並整合 OpenCV、TensorFlow及OpenVINO等函式庫，負責影像擷取、前處理、模型推論、結果顯示及辨識資訊傳輸。

影像來源採用 Stream Cam，針對投射至道路表面的網格雷射進行即時串流擷取。當道路高低或車體與地面的相對距離發生變化時，網格雷射在影像中的位置與形狀也會隨之改變。系統以影像中心作為判斷基準，將網格雷射的變化狀態劃分為三個類別：

* `normal`：網格雷射位於正常基準範圍，代表目前道路與距離狀態正常。
* `far`：網格雷射的主要變化出現在影像上半部，代表偵測目標或路面距離較遠。
* `near`：網格雷射的主要變化出現在影像下半部，代表偵測目標或路面距離較近。

完成資料蒐集、分類與模型訓練後，將訓練模型部署於 Raspberry Pi，透過 OpenCV擷取即時影像，並使用OpenVINO執行模型推論。系統實際於柏油道路環境進行測試，驗證不同道路距離及網格變化下的辨識效果。辨識完成後，Raspberry Pi會將`normal`、`far`與`near`等分類結果，透過UART單向傳輸至HT32F52352微控制器，由微控制器執行相對應的警示控制。

在微控制器與周邊控制方面，開發初期先針對蜂鳴器（AZ-1440S-P）、搖頭開關（MTS-1）及一字雷射模組進行獨立功能測試，確認各項元件的電氣特性、GPIO控制方式及實際操作效果，再整合至完整系統。

蜂鳴器由HT32F52352的GPIO或計時器輸出控制，並依據Raspberry Pi傳送的辨識結果產生不同頻率的警示音。當系統判斷距離為`far`時，蜂鳴器以較低頻率或較慢節奏發聲；當判斷為`near`時，則提高警示頻率或縮短鳴叫間隔，使使用者能夠透過聲音變化快速辨識目前的距離風險。若辨識結果為`normal`，則維持待機狀態或停止警示。

系統另外設置一組位於載具後方的安全方向警示子系統，並使用一字雷射模組投射方向警示光線。實際測試發現，微控制器GPIO的輸出電流與功率不足以直接驅動雷射模組，因此在電路中加入電晶體驅動電路，由GPIO控制電晶體的導通與截止，再透過外部較高電壓電源驅動雷射，以避免微控制器接腳過載並確保雷射能夠穩定運作。

一字雷射在未接收到方向控制指令時維持恆亮，作為載具後方的基本安全標示；當接收到左轉或右轉指令後，對應方向的雷射則改以週期性閃爍方式呈現，強化方向提示效果。雷射控制指令來自主系統的MTS-1搖頭開關，微控制器透過兩組GPIO輸入讀取開關狀態，判斷目前為左轉、右轉或中立狀態，再產生對應的控制命令。

為避免主系統與後方警示子系統之間使用實體訊號線連接，本專案採用RYLR896 LoRa模組建立無線通訊。微控制器透過UART與LoRa模組進行通訊，並利用AT Command完成模組位址、頻段及通訊參數設定。主系統讀取搖頭開關狀態後，將方向資訊封裝為簡易控制封包，再透過LoRa傳送至載具後方的子系統。

後方子系統接收LoRa資料後，解析封包中的方向控制指令，進一步控制對應的一字雷射進行恆亮或閃爍。雖然本專案採用較精簡的封包格式，但已能完成左轉、右轉及中立等基本指令的可靠傳輸，並驗證LoRa應用於前後分離式安全警示系統的可行性。

整體而言，本專案完成了一套結合人工智慧影像辨識、邊緣運算、微控制器控制及LoRa無線通訊的智慧道路安全輔助系統。系統利用網格雷射與攝影機判斷道路距離狀態，再透過UART將辨識結果傳送至HT32F52352，以不同頻率的蜂鳴器提供即時警示；同時藉由搖頭開關取得方向操作資訊，並透過LoRa傳送至後方子系統，控制一字雷射進行方向警示，達成距離偵測、聲音提醒及無線方向提示等整合功能。
