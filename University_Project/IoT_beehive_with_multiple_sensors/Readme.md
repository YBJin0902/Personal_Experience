# 專題簡介

在蜂箱內部裝置溫溼度感測器用以監測蜂箱內的環境變化且藉由在通風口處安裝伺服馬達實現開啟通風閘門避免蜜蜂長期處於不適合的生長環境中並透過重量感測器的數值回饋觀察蜂蜜產量的變化以及使用雷射模組搭配亮度感測器去偵測蜜蜂進出蜂箱的次數，各個蜂箱間會以 LoRa 傳輸技術彙整資料至接收站，接收站再藉由 NB IoT 將資料傳輸至雲端使蜂農能夠實時監控，同時為了避免蜂農忘記蜂箱的放置地點，我們會在接收站安裝 GPS 一樣藉由
NB IoT 將位置發送至雲端。

# 研究方法

本專案首先針對各感測、通訊及供電模組進行功能測試與整合驗證，確認各模組的通訊介面、控制方式及實際應用流程，並依功能將整體系統劃分為「蜂箱端感測節點」與「接收站閘道」兩大部分。

在環境監測方面，採用 AM2320 溫溼度感測器，透過 I²C 通訊介面定期取得蜂箱內部的溫度與相對溼度數據，以掌握蜂群生存環境的變化。蜂群進出次數的偵測則由 BH1750 光照度感測器與 KY-008 雷射模組共同完成。系統先將微控制器的 GPIO 設定為輸出模式，以控制雷射模組的供電與啟閉，再透過 I²C 讀取 BH1750 的照度變化。當蜜蜂通過並遮斷雷射光束時，光照度數值會產生明顯變化，系統即可依據預設門檻與事件判斷邏輯進行進出次數統計。

蜂箱重量監測採用 FSR400 壓力感測器。FSR400 為電阻式壓力感測元件，其阻值會隨受力大小而改變。系統透過分壓電路將阻值變化轉換為電壓訊號，再由微控制器的 ADC 通道進行取樣與數位化。經過多組已知重量的校正測試後，建立 ADC 數值、輸出電壓與實際重量之間的對應曲線，進而估算蜂箱重量及其變化趨勢，作為蜂蜜產量與蜂群狀態分析的參考依據。

在無線通訊架構方面，系統整合 RYLR896 LoRa、SIM7020E NB-IoT 與 SIM7600G-H 4G 通訊模組。各模組皆透過 UART 與微控制器進行通訊，預設鮑率設定為 9600 bps，並依照不同模組的 AT Command 完成初始化、參數設定、連線建立及資料傳輸。

LoRa 模組主要負責蜂箱端與接收站之間的區域性無線資料傳輸。為降低通訊碰撞及系統功耗，蜂箱端採用單向、分時傳輸機制。微控制器利用計時器中斷建立週期性排程，當指定時間到達後，各蜂箱依預先規劃的時槽輪流將溫溼度、進出次數、重量及其他感測資料傳送至接收站。接收站端則持續監聽各蜂箱所傳送的資料，並根據 LoRa 模組初始化時設定的 Address 識別資料來源。接收到資料後，系統會在資料前端加入蜂箱編號與時間資訊，再進行暫存與封包整理，以確保多個蜂箱的資料能夠被正確區分與管理。

接收站同樣透過微控制器的計時器中斷執行週期性外網上傳。當上傳週期到達後，系統會彙整各蜂箱的最新資料，並依現場網路環境選擇 NB-IoT 或 4G 作為廣域網路傳輸方式。SIM7020E NB-IoT 模組採用 MQTT 通訊協定，將資訊發布至自行架設的 MQTT Server，適合低資料量、低功耗及行動網路覆蓋較弱的部署環境。SIM7600G-H 4G 模組則採用 HTTPS 通訊，透過 HTTP POST 將資料上傳至伺服器，資料格式設計為表單格式，適用於需要較高傳輸速率及較完整網路服務的應用場域。雙網路模組的設計可提升系統在不同地區及不同電信覆蓋條件下的部署彈性與通訊可靠度。

為提供蜂箱的地理位置資訊，系統另外整合 NEO-7M GPS 模組。GPS 模組透過 UART 輸出定位資料，並可依系統需求調整傳輸速率。微控制器解析或轉送經緯度等定位資訊後，將其與蜂箱編號、感測資料及時間資訊一併上傳至伺服器。伺服器端再將經緯度資料轉換為地圖上的視覺化位置，使管理者能夠遠端掌握各蜂箱的分布位置與運作狀態。

在能源供應方面，系統採用太陽能板搭配 MPPT Solar Controller，將太陽能轉換為電能並為系統電池充電。MPPT 控制器可根據太陽能板的輸出狀態追蹤最大功率點，以提升充電效率與能源利用率，使蜂箱監測設備能夠在缺乏市電的戶外環境中長時間持續運作。

整體而言，本專案建置了一套具備環境感測、蜂群活動統計、蜂箱重量監測、區域無線傳輸、廣域網路上傳、GPS 定位及太陽能供電功能的智慧蜂箱監測系統。系統透過多個蜂箱端節點蒐集現場資訊，再利用 LoRa 將資料集中至接收站，最後根據網路條件選擇 NB-IoT 或 4G 將資料傳送至伺服器，形成一套可遠端監控、可擴充且適用於戶外部署的物聯網蜂箱管理架構。
