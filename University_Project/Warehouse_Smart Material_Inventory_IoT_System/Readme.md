# 專題簡介

本系統分為三大主題，分為：以電子紙為主的貨櫃系統、以燈號指示為主的貨架系統與門禁系統。貨櫃系統，以電子紙為核心技術並搭載 Wi-Fi 模組 (ESP-12S) 擴充了聯網功能，同時也具備掃描 RFID 與 LED 燈條的功能，能夠對物品的使用進行高效的即時管控。貨架系統，以三色燈為主也搭載了 Wi-Fi 模組 (ESP-12S) 櫃位實際位置，也是本系統的物聯網中不可或缺的一環。在所有的裝置中，都有安裝指撥開關，用於編碼所有的裝置，有助於在雲端資料庫中，編輯與管理。

# 研究方法

本專案以智慧倉儲的「器材借用、歸還與庫存盤點」為核心使用情境，建置一套結合電子紙顯示、身分驗證、物品辨識、重量偵測、燈光導引、無線通訊及最佳揀貨路徑規劃的智慧倉儲管理系統。整體架構依功能劃分為「門禁系統」、「貨架系統」與「櫃位系統」，並透過 Wi-Fi 與中央伺服器連線，形成星狀網路架構，以集中管理工單、使用者身分、器材狀態及庫存資訊。

櫃位系統

櫃位系統為本專案的主要操作介面，整合 2.9 吋電子紙模組、Barcode Scanner、電子秤、MFRC522 RFID、ESP-12S Wi-Fi 模組、指撥開關及 LED 燈條，並以 STM32F103 微控制器作為核心控制單元。

電子紙模組透過 SPI 介面與 STM32F103 通訊，用於顯示櫃位編號、器材名稱、庫存數量、借用狀態及操作提示。電子紙僅在畫面更新時消耗較多電力，且斷電後仍可長時間保留最後顯示內容，因此適合應用於需長時間維持標示資訊的倉儲櫃位。

系統依器材特性將物品分為「貴重器材」與「耗材」，並採用不同的偵測方式：

* 貴重器材：透過 Barcode Scanner 掃描器材上的一維碼或二維碼，確認器材編號及借用狀態。
* 耗材：透過電子秤量測櫃位重量變化，再依單件耗材的標準重量換算目前庫存數量。

Barcode Scanner 與電子秤皆透過 UART 與微控制器通訊。掃描器可快速讀取紙本或螢幕上的多種條碼格式；電子秤則持續回傳重量數值，由微控制器進行濾波、校正及數量換算。

在人員身分驗證方面，系統採用 MFRC522 RFID 模組，透過 SPI 介面讀取卡片 UID，確認操作者是否具備借用、歸還或盤點權限。微控制器彙整使用者身分、物品編號、櫃位編號、操作類型、數量變化及時間資訊後，進行封包編碼與簡易加密，再透過 ESP-12S Wi-Fi 模組以 TCP 方式傳送至伺服器。

門禁系統

門禁系統主要負責工單驗證與倉儲進出管理，硬體包含 Barcode Scanner 與 ESP-12S Wi-Fi 模組。

使用者進入倉儲前，先掃描工單或作業憑證上的條碼。門禁控制器將工單編號透過 TCP 傳送至伺服器，確認工單是否有效、是否在允許作業時間內，以及使用者是否具備對應權限。驗證成功後，系統才允許後續進入與揀貨作業。

此設計可將實際進出紀錄與工單資料進行關聯，確保人員、任務及器材操作具有完整的追蹤紀錄。

貨架系統

貨架系統整合三色燈模組、指撥開關及 ESP-12S Wi-Fi 模組，主要功能是標示目標貨架並協助使用者快速尋找器材。

每個貨架透過指撥開關設定唯一編號，微控制器利用 GPIO 讀取開關狀態，再將貨架編號與實際位置建立對應關係。伺服器接收到工單後，可依據器材所在位置遠端控制指定貨架的三色燈：

* 綠燈：目前需要前往或可正常取用。
* 黃燈：等待確認、盤點中或庫存需要注意。
* 紅燈：禁止取用、器材異常或庫存不足。

由於三色燈模組需要 24 V 電源驅動，無法直接由微控制器 GPIO 控制，因此電路中加入電晶體驅動級與繼電器。GPIO 僅負責輸出低功率控制訊號，再由驅動電路切換 24 V 負載，以提高控制穩定性並保護微控制器。

櫃位系統則使用 LED 燈條進一步標示實際櫃位，使系統形成「貨架粗定位、櫃位精確定位」的兩階段導引方式。

借用、歸還與盤點流程

借用情境

使用者先於門禁系統掃描工單，由伺服器確認身分、工單內容與器材權限。驗證通過後，伺服器依工單中的器材位置計算建議揀貨路徑，依序啟動目標貨架的三色燈及目標櫃位的 LED 燈條。

到達櫃位後，使用者以 RFID 卡進行身分確認。若借用貴重器材，須掃描器材條碼；若取用耗材，則由電子秤偵測重量減少量並換算取用數量。操作完成後，櫃位系統更新電子紙內容，並將借用紀錄與庫存變化傳送至伺服器。

歸還情境

使用者掃描歸還工單後，伺服器啟動對應貨架及櫃位的燈光導引。使用者到達指定櫃位並通過 RFID 驗證後，系統依器材類型執行確認。

貴重器材需再次掃描條碼，以確認歸還物品與原借用紀錄一致；耗材則透過電子秤偵測重量增加量。完成歸還後，系統更新庫存、電子紙畫面及器材狀態，並將歸還時間與操作人員記錄至伺服器。

盤點情境

盤點作業可由伺服器下達指定貨架或櫃位的盤點任務。工作人員依燈光指示到達目標位置，並使用 RFID 完成身分確認。

對於貴重器材，系統逐一掃描條碼並與伺服器帳面資料比對；對於耗材，則讀取電子秤數值並換算實際數量。若發現條碼缺漏、器材位置錯誤或重量與帳面庫存不一致，系統會回報盤點異常，並透過三色燈或 LED 燈條提示需要複查的區域。

最佳揀貨路徑演算法

伺服器端依據貨架與櫃位編號建立虛擬倉儲地圖，並將走道交會點、貨架及櫃位位置表示為圖形結構中的節點，節點之間的可通行距離則表示為邊。

路徑規劃分為兩個階段：

1. 使用 Floyd–Warshall 演算法預先計算任意兩個節點之間的最短距離。
2. 使用回溯法排列工單中所有待揀貨節點，找出總移動成本最低的拜訪順序。

例如，某張工單需要經過節點 0、1、2，系統會先以深度優先搜尋取得一組可行路徑，例如：

`0 → 1 → 2`

此路徑成本會作為目前的最佳解上限。後續執行回溯搜尋時，若某一層累積的移動成本已經大於或等於目前最佳解，便立即停止搜尋該分支。此方法屬於分支限界式剪枝，可減少不必要的排列組合與遞迴次數，提高多個揀貨點情境下的路徑計算效率。

系統整合成果

本專案完成一套具備以下功能的智慧倉儲管理架構：

* 以電子紙即時顯示櫃位、器材及庫存資訊。
* 使用 Barcode Scanner 管理貴重器材。
* 使用電子秤估算耗材取用量及剩餘庫存。
* 使用 RFID 執行人員身分及操作權限驗證。
* 使用三色燈與 LED 燈條提供貨架及櫃位導引。
* 使用指撥開關設定各系統的唯一位置編號。
* 透過 ESP-12S、UART、TCP 與伺服器交換資料。
* 建立借用、歸還、盤點及異常追蹤機制。
* 結合 Floyd–Warshall、回溯法與剪枝策略規劃最佳揀貨路徑。

整體系統將嵌入式控制、感測器整合、物聯網通訊、倉儲資訊管理及最佳化演算法結合，可降低人工盤點與器材登記錯誤，縮短尋找及揀貨時間，並提升倉儲作業的可追蹤性與管理效率。
